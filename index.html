Rendimiento P.D.V.

El rendimiento semanal de cada punto de venta, en un solo lugar: inventario, ventas, compras, margen y utilidad calculados automáticamente y guardados en un historial por sede — todo se procesa en este computador, ningún dato sale de aquí.

¿Qué quieres generar?

1. Cargar archivos (una o varias sedes)

Arrastra aquí los Excel semanales (.xlsx / .xls)

Puedes soltar varios archivos a la vez — uno por cada sede

2. Sedes cargadas

Verifica el nombre de cada sede y resuelve las columnas pendientes de clasificar (si las hay) antes de generar el informe.

Se activa cuando todas las sedes cargadas estén listas.

2. Sede nueva — Inventario Inicial

No hay semanas guardadas todavía para esta sede, así que no se puede encadenar automáticamente. Escribe el Inventario Inicial de esta primera semana (de ahí en adelante, la herramienta lo calcula sola cada semana a partir del Inventario Final anterior).

3. Revisar clasificación

Confirma o corrige a qué balde pertenece cada tipo de documento nuevo para esta sede. Las etiquetas ya conocidas no vuelven a preguntarse.

Se activa cuando el archivo esté cargado y clasificado (y, si la sede es nueva, cuando escribas el Inventario Inicial).
